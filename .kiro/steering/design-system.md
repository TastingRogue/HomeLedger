# Smart Finance Design System

## Visual Foundation
- Premium dark-mode financial dashboard
- Background: very dark navy/charcoal (#0b1118)
- Surface panels: slightly lighter (#131a24)
- Cards/elevated: (#1a2332)
- Sidebar: darker than main content (#0a0f16)
- Borders: subtle 1px (#1e2a3a)
- Border radius: 8-12px
- Typography: Inter/system-ui, clean and compact
- Professional fintech/SaaS aesthetic
- No excessive gradients, glassmorphism, or flashy effects

## Color System
- Green (#22c55e) = positive values, income, savings, active status
- Red (#ef4444) = expenses, negative balances, warnings
- Blue (#3b82f6) = accounts, transfers, informational elements
- Purple (#8b5cf6) = goals, planning, selected nav items
- Orange/Yellow (#f59e0b) = warnings, subscriptions, attention
- White/light gray (#f1f5f9) = primary text
- Muted gray (#64748b) = secondary metadata

## Layout
- Fixed left sidebar ~235px
- Main content with generous but efficient spacing
- Consistent top header per page
- Page title + description on left
- Date range/filter controls on right
- Cards use consistent padding (16-20px) and hierarchy
- Tables dense but readable
- Charts minimalist, integrated into cards

## Sidebar Navigation
NAVEGACION: Panel Principal, Cuentas, Transacciones, Transferencias, Suscripciones
PLANIFICACION: Metas, Presupuestos, Calendario de Pagos
ANALISIS: Categorías, Reportes, Alertas
CONFIGURACION: Configuración, Etiquetas, Importar Datos

Selected item: purple highlighted background

## Key Rules
- NO floating action button
- Quick actions exist in sidebar/interface
- All modals for creating/editing (not page navigation)
- Categories have type: Gasto, Ingreso, Ambos
- Credit accounts: balance = used credit (transfers IN reduce debt)
- Currency: MXN with MX$ prefix
